explanation:
  role: 教师讲解稿
  body: |
    把等式想成**平衡的天平**：两边质量相等。

    **性质 1**：两边同时加或减**同一个数**，仍然平衡（等式仍成立）。
    例：$x = 5$，两边都加 3 → $x+3 = 8$，仍成立。

    **性质 2**：两边同时乘或除以**同一个不为 0 的数**，仍然平衡。
    例：$3x = 15$，两边都除以 3 → $x = 5$。
    但两边都乘以 0 会把任何式子变成 $0=0$，**丢失信息**，所以不许。

    移项变号就是性质 1 的简写：把 +5 移到另一边，等于两边同时减 5。

      - "左边：x+5-5=x；右边：12-5=7。"

# 等式的性质

性质 1：同加减同一数；性质 2：同乘除同一**非零**数。天平模型帮你记忆。
