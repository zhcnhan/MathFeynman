    温度零下 5 度、欠 3 元、海平面以下 50 米——都需要一种比 0 小的数：**负数**。

    画一条带箭头的直线，取一点为**原点 0**，规定向右为正方向，
    单位长度一致——这就是**数轴**。负数在 0 的左边，正数在 0 的右边。

    **相反数**：只有符号不同的两个数，如 3 和 -3，它们在数轴上离 0 一样远。

    **比较大小**：数轴上右边的数总比左边的大，所以负数 < 0 < 正数；

# 负数与数轴

负数表示相反意义的量；数轴上左边小右边大，负数总在 0 的左边。
