## 2. 蓝图分层结构与学段主题骨架（起草基线，供 Euler 展开细节条目）

> 每条目仍用现有字段：id/title/topic/objectives(≤3)/prereqs/difficulty/requires_thinking/
> anchors(可选，指向任意学段已入库节点 id)。level 间推进由 selfextend 学段顺序 +
> 用户掌握前一学段控制；prereq 一般 level 内，anchors 可跨 level 引用。

- **primary（既有 21 条 + 修订批 A/B/C，转正后为基础）**：数与运算 / 量与测量 / 图形与几何
  / 代数思维 / 应用题建模 / 统计与概率。
- **middle（现有 4 条 → 扩为全段，方向见 REVIEW-blueprint.md D）**：
  有理数四则与运算律 → 整式 → 一元一次方程（锚 0101–0104）→ 方程应用与不等式
  → 二元一次方程组 → 实数与根式 → 平面几何（角/相交平行/三角形全等与相似/勾股）
  → 一次函数（锚 high.0201 前置或同级）→ 概率统计初步。
- **high（新起草，P1）**：集合与常用逻辑、等式不等式（一元二次/含参/基本不等式）→
  函数（概念/性质/幂指对/三角函数与图象）→ 数列 → 平面向量 → 立体几何初步 →
  解析几何（直线与圆/圆锥曲线）→ 导数及其应用 → 统计与概率（计数原理/二项式/正态）。
- **college（新起草，P2；大学基础三件套 + 工具线）**：
  一元微积分（极限/连续/导数/积分/微分方程初步/级数）→ 多变量与向量微积分 →
  线性代数（行列式/矩阵/向量空间/特征值/二次型）→ 概率论与数理统计 →
  离散初步（集合论/图论/逻辑）与数值计算初步（视需要并入 ai）。
- **ai（新起草，P3；面向 AI/大模型/量化交易的数学）**：
  机器学习数学基础（概率+线代+优化的汇合）→ 凸优化与数值优化 → 信息论与熵 →
  矩阵分析补充/范数与正则化 → 高维概率与统计学习理论入门 → 时间序列与随机过程 →
  量化应用（金融数学基础：期望/方差/协方差矩阵/组合优化/回测统计）。
  注：ai 学段的编排需在 college 完成后自然衔接；某些主题（随机过程）也可作 college
  拓展，起草时给出建议并标 thinking:true（默认 deep 档）。

## 3. 工程分阶段（每阶段独立汇报，全部只写蓝图不生成内容）
- 前置：完成当前"blueprint 修订批 A/B/C"（primary/middle 修订 + audit 锚点检查）。
- P1：high.yaml 全段草案 + audit 全绿 + 抽几条写锚点级示例供精核。
- P2：college.yaml 全段草案 + audit。
- P3：ai.yaml 全段草案 + audit（含 ai 学段依赖 college 的衔接说明）。
- P4（配套，北极星需要）：high+ 自动入库策略与质量护栏升级——high+ 默认自动入库并
  靠 sympy 校验 + 白名单 + **掌握/费曼通过作为内容旁证 + 纠错召回**替代强制人审；
  保留"内容问题率 > 阈值 → 该主题转草稿待检"的自动熔断。此配套与 P1 蓝图一起评审。
- 每个新学段蓝图 draft 就绪后，由用户在"到达该学段前"滚动精核转正（运行期仍无人审）。

## 4. 验收
- content/roadmap/ 存在 {primary,middle,high,college,ai}.yaml，全部条目数 ≥ 预估下限、
  audit()（含锚点存在性）全绿、ROADMAP_AUDIT.md 更新。
- 端到端模拟：小学通关 → 初中自动生成并掌握 → …（模拟推进到至少高中首批），
  全程无人工审核动作（测试自动化模拟，AI 出稿用 stub/mock）。
- 运行期懒生成确认：mastered 比例到达新学段边界时，系统自动开始该学段首批生成，
  无需任何代码/人工动作（对应 docs/10 §4 全学段扩展）。

## 5. 风险与口径
- 蓝图规模大（估计小学≈40+、初中≈120+、高中≈200+、大学≈300+、AI≈150+ 条目草案），
  P1–P3 分批起草，质量靠"欧拉起草 + 架构侧抽查 + 用户到段前精核"三关；不做一次性
  全文人工精核。
- 内容质量：大学/AI 内容靠运行时护栏 + 费曼旁证 + 纠错召回，蓝图只保证"顺序与范围
  对"，不保证单条讲解零错——与北极星"运行期无人审"一致。
- 预算：蓝图起草是文档级 LLM 用量（远小于内容生成），仍受 token 限额保护。
